## [0.1.0] - 2026-09-26

### Added

- Open and edit `.bfly` documents in a joplin panel.
- Load and save documents through the Butterfly embed protocol.
- Attach canvas exports as `.svg` to your notes.
- Set the origin (URL) for the butterfly embed as a joplin setting.
- Set the language for the butterfly embed as a joplin setting.
